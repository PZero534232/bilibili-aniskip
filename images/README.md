# README 配图

这里是 README「使用」一节的截图。三张，文件名固定（README 里就是按这三个名字引用的）：

| 文件名      | 截什么             | 要点                                                                                                                                       |
| ----------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `pill.png`  | **播放页 + 胶囊**  | 找一部能识别出番名的番（胶囊上显示「番名 第N集　N 段」，`ask` 模式下还会多一个「跳过」）。把播放器右上角连同胶囊一起截进来，能看到 🎯 ⚙ – 三个按钮 |
| `bind.png`  | **绑定面板**       | 点「绑定」打开面板，**先搜一次并选中一条**，让候选列表、「将绑定」那一行、当前是第几话、生效范围、保存按钮都在画面里                            |
| `mark.png`  | **标记工具条**     | 点 🎯 打开工具条，**先标一组 OP**，让工具条里出现已标条目、播放器底部进度条上出现刻度（蓝＝片头 / 橙＝片尾）                                  |

截图注意：

- 浏览器缩放保持 100%，窗口宽度 ≥ 1200 像素（否则面板会被挤窄）
- **别用网页全屏**截胶囊 —— 网页全屏时胶囊会按设计隐藏
- 截播放器区域就够，**不要带上 B 站账号头像／昵称**
- PNG 就行，单张控制在 1MB 以内
