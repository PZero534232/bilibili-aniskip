# Bilibili 番剧 OP/ED 跳过

给 B 站播放器加一个能力：**自动跳过番剧的片头 / 片尾 / 总集篇回顾** —— 包括 B 站官方没有时间戳的「用户上传」搬运番。

> Auto-skip anime OP/ED on Bilibili, including user-uploaded episodes that have no official timestamps. Timestamps come from the AniSkip / Anime Skip databases (keyed by anime ID + episode number), so it works no matter which site hosts the video.

单文件用户脚本（Tampermonkey / Violentmonkey / 暴力猴），无依赖、无构建。当前版本 **0.5.0**。

## 它解决什么问题

B 站只给**番剧区正版番剧**提供官方片头片尾时间戳。UP 主搬运、字幕组投稿的番剧（B 站标记为「用户上传」）没有任何 OP/ED 数据，于是：

| 常见思路 | 为什么不够 |
| --- | --- |
| 解析弹幕里的「空降 / 正片开始」 | 冷门番、老番、弹幕关闭或清空的视频里根本没人刷 |
| 众包标记（SponsorBlock 之类） | 冷门新番、刚上线的剧集没有覆盖 |
| 固定秒数（每集都跳 90 秒） | 必然错。同一部番每集 OP 起点都不一样（实测 1995 年的 EVA 各集就不同） |
| 等 B 站官方 | 官方只处理正版番剧区，搬运稿永远等不到 |

**关键点**：AniSkip 和 Anime Skip 这两个动画时间戳库是按「**番剧 ID + 集数**」组织数据的，跟你在哪个网站看没关系。所以「B 站没有时间戳」这件事可以用外部数据补上。

实在补不上（太冷门、太新、数据库里没有）时，脚本还能让你**手动标一次 OP/ED**，之后靠画面指纹自动跳过。

## 特性

- ⏭ **自动跳过 OP / ED / 回顾** —— 三个独立开关，回顾默认关（很多人想看）
- 🔍 **怎么搜都能中** —— 中文名、罗马字、日文原名、英文名、简写（`Re:0`）都行
- 📺 **多季连播合集** —— 一个视频塞 60 个分P、横跨 5 季，自动按分P分段对齐数据库条目（一段可含多个季度）
- 🔗 **手动绑定是一等公民** —— 标题乱码 / 没有番名 / 自动认错时，搜一次绑一次，整个合集每集复用
- 🎯 **本地手动标记（冷番兜底）** —— 云端没有时间戳的番，点胶囊上的 🎯 边看边标 OP/ED 的起止帧，脚本认画面指纹自动跳过，同番跨集复用
- 🛡 **默认不自动识别** —— 普通视频零请求、零干扰，绝不误伤
- 🫧 **状态胶囊** —— 播放器上常驻，随时看识别状态；可用鼠标／手指拖到任意位置，可以**收起成一颗状态圆点**，**网页全屏时自动隐藏**
- ↩️ **跳错能撤回** —— 每次跳过后有 4 秒的「撤回」窗口
- ⬅️ **起点偏移 / 整段平移** —— 搬运版剪过或加过片头时把时间戳对齐回来
- ⏩ **自动切下一集** —— ED 跳完直接切下一个 P／下一话（设置开关，默认关）

## 快速开始

1. 打开任意 B 站**视频页**（`bilibili.com/video/BV…`）
2. 播放器上会出现胶囊（默认显示「未识别」）—— 脚本**默认不自动识别**，普通视频零请求、零干扰
3. 二选一：
   - **手动**：胶囊上点「绑定」→ 搜番名 → 选中 → 保存
   - **自动**：点 ⚙ → 「自动识别」改成 `ask`（识别后问你要不要跳）或 `auto`（够可信就自动跳）
4. 开播。OP/ED 到了会自动跳过；跳完 4 秒内可以点「撤回」回到原位

## 使用方法

### 状态胶囊

打开视频页后，播放器上会出现一颗胶囊，显示当前状态：

| 胶囊显示 | 含义 |
| --- | --- |
| `番剧跳过 · 未识别` | 没认出这是番剧（默认状态）。想看效果就点「绑定」手动指定 |
| `未找到集号` / `标题无番名` | 认出是番剧但缺信息 → 点「绑定」手动指定 |
| `没匹配到番剧，可点「绑定」` | 标题抽得出番名，但数据库里没搜到（灰点，不是错误） |
| `数据源限流(429)，稍后重试` | 时间戳接口被限流（AniSkip / Anime Skip / AniList / Bangumi 都可能有），稍后自动重试 |
| `请求超时，稍后重试` | 接口响应超时 |
| `网络不通，稍后重试` | 断网或接口不可达 —— 和「数据库里没有」是两回事 |
| `已标记「不是番剧」· 不会再跳` | 这个视频被标记过不是番剧；胶囊上点「取消」恢复 |
| `绑定的季和这一话对不上` | 旧绑定没有季链、或绑到了别的季 —— 脚本正在自动补算季链，也可以重新绑定 |
| `葬送的芙莉莲 第3集　12 段` | 识别成功，共 12 段可跳时间戳 |
| `葬送的芙莉莲 第3集　12 段　跳过` | **ask 模式**：识别成功但没自动跳，点「跳过」跳**正在播的那一段** |

### 胶囊上的按钮

| 按钮 | 作用 |
| --- | --- |
| **绑定** / **改** | 打开绑定面板，手动指定这是哪部番（已绑定时显示「改」） |
| **跳过** | ask 模式下才出现。点它跳**你正在看的那一段**：时间戳还没到就等它开始，已经播过去了就不会把你甩到别的段上 |
| **🎯** | 打开**标记工具条**（本地手动标记 OP/ED，见下文） |
| **⚙** | 打开设置面板 |
| **–** | 把胶囊收成一颗状态色圆点；点圆点展开。收起状态会记住 |
| **取消** | 只在这个视频被标记过「不是番剧」时出现，点一下恢复 |

胶囊可以**用鼠标／手指直接拖到任意位置**（拖动过程中不会误触发「跳过」），位置会记住；拖烦了在设置里点「重置位置」回到右上角。检测到 B 站**网页全屏**时胶囊会整体隐藏（连圆点都不留），退出全屏自动恢复；浏览器**真实全屏**本来就不显示胶囊。

### 自动识别三档

设置里的「自动识别」：

| 档位 | 行为 |
| --- | --- |
| `off`（**默认**） | 不做任何基于标题的自动识别，普通视频完全不触发。**手动绑定过的番剧仍然生效** —— 绑过就代表你要它跳 |
| `ask` | 自动识别，命中后只显示在胶囊上（带「跳过」按钮），你点了才跳 |
| `auto` | 自动识别，且**置信度 ≥ 60**（`confThreshold`）时直接跳；没过门槛就退化成 `ask` 的样子 |

置信度低于 **35**（`hintThreshold`）时连识别成功的提示都不弹，结果照旧显示在胶囊上。

### 手动绑定番剧

标题乱码、没有番名、认错番、或者你想指定具体是哪一季时用：

1. 点胶囊上的「绑定」
2. 在搜索框里输番名（中文 / 罗马字 / 日文 / 英文 / 简写都行），点「搜索」；或点「用标题自动填」
3. 从候选里选中正确的番剧 —— 面板上「将绑定」那一行会写清你选的是哪一条；多季连播合集还会标出**你选的这条落在第几段**
4. 填「当前是第几话」：填**这一集在这个合集里的序号**。比如合集共 32 个视频、你在看第 21 个，就填 21，脚本会自己算出它是第几季第几话
5. 选「生效范围」：默认选中最宽的一档 —— 有 UGC 合集时是「整个合集（含合集里其他视频）」，否则是「这个视频的全部分P（推荐）」；也可以限成「只在这一 P 生效」
6. 保存

多季连播合集在**季边界算出来之前「保存」是灰的**（面板上会写「正在推算季边界…」）：存成没有季链的单季绑定会让整个合集用错季的时间戳，宁可等这一两秒。

候选列表里会出现**整个系列的条目**（第2クール、第二季、第三季…）：中文名在 AniList 上常常搜不全（实测「无职转生」只回 3 条、没有第三季），脚本会把算季链时顺手拿到的同系列条目补进候选，并在下面写明「共 N 条候选」—— 框子能上下滚。

旧版本（≤0.4.5）存下的、**没有季链的绑定**会被自动补算季链并写回；补算完成前，如果这一话明显不属于你绑的那一季，脚本**宁可先不跳**（胶囊上写「绑定的季和这一话对不上」），也不会拿错季的时间戳去跳。

### 本地手动标记 OP/ED 帧（冷番兜底）

数据库里没有的番（太新、太冷门），可以手动标一次。

**打开**：点胶囊上的 **🎯**，工具条会浮在播放器左下角（非模态，不挡画面，可以拖到任意位置，位置会记住）。再点一次 🎯、或点工具条右上角的 **✕** 退出。标记模式是持久化状态，刷新页面后工具条会自己回来。

**怎么标**：

1. 播到 OP 开头 → 点「**标 OP 开始**」
2. 播到 OP 结束 → 点「**标 OP 结束**」（ED 同理：标 ED 开始 / 标 ED 结束）
3. 标完立刻生效，不用刷新页面 —— 脚本会开始按画面指纹认 OP/ED

已标的条目列在工具条里：**点正文**跳到那个时间点，**点 ✕** 删掉这一条，**清空本番标记**全部清掉。进度条上会在标记的起点位置画一条 2px 刻度（片头蓝、片尾橙）帮你确认标得准不准。

**生效前提**（不满足就是「标了没反应」）：

| 前提 | 说明 |
| --- | --- |
| 当前视频**已绑定**这部番 | 标记是按番剧绑定存的。没绑定时点标记按钮会提示「先绑定 / 识别这个番剧再标」 |
| **云端没有这一集的时间戳** | 云端（AniSkip / Anime Skip）有数据时一切以云端为准，本地指纹只在云端没给段、或网络失败时兜底 |
| **OP 必须标了「结束」** | 只标了开始的 OP 视为「还没标完」，**整条不参与匹配**。ED 可以不标结束，那就跳视频末尾 |
| 要**播到**那一帧 | 标完不会立刻跳，得播到 OP 出现那一刻；**暂停时不抽帧** |
| 画面能读出来 | 同源画面直接读像素；画面被重裁、压制参数不同、贴了大面积字幕时指纹可能认不出 |

**它是怎么认的**：

```
每 250ms 抓一帧 → 缩到 160×90 灰度 → 8×8 平均哈希（64 位）
   → 和你标的那一帧比 Hamming 距离（≤ 10/64 算命中）
   → 连续 2 帧命中才算「认到」（防单帧误判）
   → 跳到「认到的那一刻 + 你标的时长（结束 − 开始）」
```

几个要点：

- **落点用的是你标的「时长」，不是绝对秒数** —— 所以同一部番换集、OP 位置不一样也能对上
- 同一个指纹**一集只跳一次**，跳完还有 3 秒静默期（防止落到标记帧附近又被认一次、连着跳）
- 标在 OP 里**相对静止、有标志性的一帧**（开场定帧、标题卡那种）最稳；标在快速运动的画面上，连续两帧差异可能超过阈值，那一集就会漏

**换集怎么表现**：标记挂在**番剧绑定**上（不是挂在某一集），所以同一部番的每一集都自动复用 —— 但每条标记记着「标在哪一集」，进度条上的刻度**只画在标它的那一集**。换集后 OP/ED 的绝对位置大概率不一样，照旧画就是画个假位置（跳过不受影响，落点只用时长）。工具条状态行会写明「标记标于 BV… 第2P（本集按指纹复用，不画位置）」。

> 0.5.0 早期标的、没有记集号的标记仍会画在所有集上（不然老标记会凭空消失）；重新标一次就带上集号了，工具条会提示「N 条旧标记没记集号」。

### 设置项

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 自动识别 | `off` | 见上文三档 |
| 跳过 OP | 开 | |
| 跳过 ED | 开 | |
| 跳过回顾 Recap | **关** | 总集篇的回顾片段，很多人想看 |
| 跳过「融进正片」的 OP/ED | **关** | 有些番没有独立 OP 段，OP 和画面融在一起播（每集还可能不一样），跳过会切掉正片内容 |
| 跳过偏移（秒） | `0` | 在数据库给的时间戳上再挪一点。正数＝多跳（跳过 OP 后的黑屏／静帧），负数＝少跳（留住 OP 尾巴）；最多减到片段起点，不会倒着跳。范围 ±30 |
| 片头/片尾整段平移（秒） | `0` | UP 主在开头多加了片段时用：OP/ED 的**起点和落点一起**挪。比如开头多加了 20 秒就填 20。范围 ±30 |
| 撤回提示秒数 | `4` | 跳过后「撤回」按钮停留多久，0 = 不显示 |
| 显示跳转提示 | 开 | 跳转时弹提示 |
| 优先用合集单集标题 | 开 | UP 主在合集里改过的标题往往比原始标题干净 |
| 隐藏胶囊（普通视频） | 关 | 勾上后，未识别出番剧的普通视频上不显示胶囊（连收起成的小圆点也一起藏）；识别成功／已绑定的番剧照常显示。想找回入口用油猴菜单 |
| 自动切下一集 | **关** | ED 跳完直接切下一个 P／下一话（依次退化：播放器的下一集按钮 → 同 BV 分P → UGC 合集下一话）；只给「ED 后面没有彩蛋」的番用 |
| 胶囊位置 | —— | 胶囊拖动后位置自动记住；点「重置位置」回到右上角 |
| 清空缓存 | —— | 按钮。清掉识别结果与时间戳缓存，下次识别重新联网查 |

Tampermonkey 面板里有两个入口（和胶囊上的按钮等价）：

- 🔍 绑定 / 识别番剧

## 工作原理

### 认出这是哪部番

```
标题 → 抽出候选番名（引号「」《》里的优先）
     → 候选打分排序（表意文字数量 − 噪声词 − 括号残片 …）
     → 中文名走 Bangumi 桥换成日文原名
     → AniList 一次拿到 AniList ID + MAL ID
     → 若是多季连播合集，沿 relations 推出季链
     → AniSkip + Anime Skip 双源取时间戳，合并去重
     → 区间校验 + 置信度打分 → 决定跳 / 提示 / 沉默
```

两个容易踩的坑，这个脚本处理了：

- **AniList 不能当中文检索用。** 它只认恰好写在条目 `synonyms` 里的中文，直接搜「葬送的芙莉莲」是 0 条。所以中文名先走 Bangumi（`api.bgm.tv`）拿日文原名，再用日文原名去 AniList 查。
- **UP 主的标题里，真实番名通常在全角引号里**（`「」`、`《》`）。整条标题直接拿去搜会搜回完全无关的番。

### 跳过与撤回

- 轮询播放进度，命中可跳区间就跳到「区间结束 + 偏移」，并把这一段记进「本集已跳过」（**同一段一集只跳一次**）
- 跳过后弹出「撤回」，默认停留 4 秒；撤回回到**原来的那一秒**，并且这一段不再自动重跳（换集／换视频自动复位）
- `auto` 模式的置信度门槛没过、或区间是「融进正片」的类型时，宁可**只提示不跳**
- 切 P / 切视频时会作废迟到的识别结果（代际令牌），不会拿上一个视频的时间戳跳当前视频

### 本地指纹（手动标记）

见上文[本地手动标记](#本地手动标记-oped-帧冷番兜底)。一句话：云端优先，云端没有才用你标的画面指纹；指纹命中后按你标的**时长**落点。

## 数据源

| 数据源 | 用途 |
| --- | --- |
| [AniSkip](https://aniskip.com/) | 时间戳，免认证、显式 start-end 区间，主键 MAL ID |
| [Anime Skip](https://anime-skip.com/) | 时间戳，分节标记制，主键 AniList ID |
| [AniList](https://anilist.co/) | GraphQL：番名检索、AniList ID + MAL ID、续集关系（季链） |
| [Bangumi 番组计划](https://bgm.tv/) | 中文名 → 日文原名的桥 |
| [B 站 view 接口](https://api.bilibili.com/) | 拿标题、分P、UGC 合集信息（只读，不带账号） |

## 隐私

- 只用公开只读 API，不带任何账号信息，不收集、不上传任何数据
- 设置、绑定、本地标记、缓存全部只存在本地（`GM_setValue`）
- 请求域名：`api.aniskip.com`、`api.anime-skip.com`、`graphql.anilist.co`、`api.bgm.tv`、`api.bilibili.com`

## 已知限制

- 数据库里没有的番（很新的、太冷门的、OVA、部分国产番）识别不到 —— 会显示「未识别」，不会瞎跳；这类可以用[本地手动标记](#本地手动标记-oped-帧冷番兜底)
- 有些番的 OP 融进正片画面里（每集位置都不同），跳过会切掉正片，所以这类区间默认**不跳**
- 本地指纹需要画面可读、且和标记那一帧足够像：重裁、加台标、压制差异大的源可能认不出
- 需要一个能对上的番名。标题里完全没有番名时请手动绑定
- 搬运的剧场版 / 合集视频可能对不上数据库条目
- 原生 `<video>` 全屏（不是网页全屏）时工具条挂不进去，此时看不到标记工具条

## 常见问题

**Q：会误跳正片吗？**
默认 `off` 完全不自动识别；`auto` 模式要过置信度门槛（60 分）才跳；每次跳过后 4 秒内可以点「撤回」回到原位。

**Q：打开了却什么都不跳？**
看胶囊上的提示：`未识别` = 标题没认出番剧，用「绑定」；`没找到集号` = 标题里没有集数，绑定面板里手动填；`没匹配到番剧` = 名字抽出来了但库里没有，换个关键词绑定；`数据源限流(429)` / `请求超时` / `网络不通` = 接口挂了或被限流，过一会儿重试（这类失败不会写进缓存）；`这一话不跳` = 数据库里这一集没有可用时间戳，可以改用本地标记。

**Q：ask 模式怎么跳？**
识别成功但不会自动跳，胶囊上会多一个「**跳过**」按钮 —— 点它跳**你正在看的那一段**（时间戳没到就等它开始；已经播过去了就不会把你甩到别的段上）。

**Q：搜索搜不到我的番？**
中文名要先经 Bangumi 桥换成日文原名，才能拿去 AniList 查；桥没命中时中文名会搜不到。**换成日文原名或罗马字再搜一次**（比如「葬送的芙莉莲」搜不到就搜「葬送のフリーレン」或 `Frieren`），通常就有了。搜不到不等于没有数据，先换个写法试。

**Q：标了标记却没跳过？**
按顺序查：① 当前视频**绑定**这部番了吗（没绑定标记不生效）；② 云端是不是已经有这一集的时间戳（有就用云端，本地不参与）；③ OP 是不是**没标结束**（只标开始的 OP 不参与匹配）；④ 有没有**播到**那一帧（暂停不抽帧）；⑤ 标的是不是快速运动的画面（换个静止的标志性画面重标一次）。

**Q：换集后标记还在，进度条刻度呢？**
标记跨集复用是设计（标一次整季有效）。刻度**只在标它的那一集**画 —— 别的集 OP 位置不一样，画出来是假位置；跳过本身不受影响。工具条状态行会写明标记标于哪一集。

**Q：换视频 / 切分P 之后要重新弄吗？**
不用。B 站是单页应用，脚本会检测地址和分P变化自动重新识别。绑定过的番剧整个合集都覆盖。

**Q：缓存存在哪？能清吗？**
识别结果、时间戳、搜索负结果都会本地缓存以加速。设置面板里有「清空缓存」；清掉后下次识别会重新联网查。搜索连续搜不到、怀疑是缓存问题时清一下最省事。

**Q：想排查「为什么没跳 / 为什么搜不到」？**
脚本在页面上挂了调试对象 `__biliAniskip`，控制台里可以直接问它：

```js
// 搜索为什么没结果
__biliAniskip.api_.searchByName('葬送のフリーレン')
  .then(r => console.log('结果条数', r.length, '失败记录', __biliAniskip._runtime.netFail));

// 当前识别状态（结果 / 失败原因 / 本地标记）
console.log(__biliAniskip._runtime.result, __biliAniskip._runtime.localSegs);
```

- 修复 **`ask` 模式和 `auto` 一模一样**：`autoDetect` 只在识别入口读一次，结果一出来就无条件启动轮询，于是「由你决定要不要跳」实际上直接跳了。现在 `ask` 只显示（胶囊上多一个「跳过」按钮，点了只跳你正在看的那一段），`auto` 才自动跳
- 修复 **`confThreshold` / `hintThreshold` 是死配置**（定义了从来没被读过）：`auto` 现在真的要置信度 ≥ 60 才跳，没过门槛退化成 `ask`；低于 35 分连识别提示都不弹
- 修复 **「不是番剧」黑名单写了不同的键**：老实现只写黑名单键的第一个（有 UGC 合集时写 `s:{seasonId}`，没有时写 `b:{bvid}`），同一个按钮在不同稿件上写进不同的表。现在固定按 BV 粒度
- 修复 **拉黑过的视频被手动绑定压过去**：黑名单检查现在在绑定分支之前（用户更晚、更明确的那次表态要算数）
- 修复 **网络失败被当成「这一集没有时间戳」**：四个接口的 `catch` 全部吞成 `[]`，UI 上「上游没有」和「网络挂了／被限流」长得一模一样。现在失败会明确报 `网络请求失败，稍后重试`，**且不写缓存**
- 修复 **负缓存过长**：上游明确回答「搜不到 / 没有这一集」的结果原来按 7 天（搜索 30 天）缓存，上游后来补了数据也迟迟不生效。现在负缓存按 6 小时过期；同理分季规则的网络失败也不再按 30 天缓存（只有 404 这种明确答复才缓存）
- 修复 **季链里的剧场版过滤不掉**：AniList 关系查询漏了 `format` 字段，而下游靠 `format` 剔 MOVIE/MUSIC —— 只有「同名搜索」那条路真的在过滤。顺带把 `CHAIN_VERSION` 升到 5，作废旧算法留下的季链缓存（老绑定里的季链同样会被忽略，重开面板保存一次即可）
- 修复 **切 P / 切视频时旧识别结果覆盖新上下文**（最坏情况是用上一个视频的时间戳去跳当前视频）：`rerun` 现在带代际令牌，迟到的结果一律作废
- 修复 **监听器泄漏**：`startMonitor` 每次给 `<video>` 挂 3 个匿名监听却从不解绑，而换 P 就会调一次 —— 现在句柄留着，`stopMonitor` 一并摘掉
- 修复 **SPA 轮询重复注册**：1.2 秒的定位轮询句柄原来不保存、也不防重复注入，脚本跑两份就有两条链。现在有 `booted` 守卫
- 修复 **胶囊样式在 CSP 拦掉 `<style>` 时完全裸奔**：关键外观（背景 / 圆角 / 圆点 / 分隔线）改为内联，和面板一个待遇
- 修复 **GM 存储被整份 view JSON 撑爆**：缓存入盘前只留识别用得上的字段（长简介、封面、头像、每集 arc 全部丢掉）
- 修复 **防抖窗口（800ms）里关页丢写**：`pagehide` / 切后台时立刻落盘
- 修复 **季链展开一次性并发 24 个 AniList 请求**（限流 90 次/分钟，冷启动容易 429）：改成每批 4 个
- 清理死代码与死配置：`applyTitleOffset`（读一个从来没人写的 `titleOffset` 字段）、`noFocusAll`、`runtime.lastSegKey`、`CACHE_TTL.bind`、集号正则里重复的 `話`
- 补齐胶囊文案：`没匹配到番剧` / `番名不太确定` / `网络请求失败` 原来都会掉进「识别失败」的红点，现在各归其位（灰点／橙点）
- 文档与代码对齐：撤回提示默认值写的是 8 秒（实际 0.4.4 起就是 4 秒）、设置表漏了「跳过偏移」、用例数写死成 193（早就对不上）。测试新增 `-q` 只打失败与汇总

### 0.4.4
- 修复**「撤回」之后还是会被自动跳过**：撤回时把「本集已跳过这段」的记录删掉了，而轮询是 50ms 一次、撤回又把播放头送回区间内部，于是下一轮立刻重新跳过 —— 点了等于没点。现在记录保留（这一集这段不再自动跳，换集／换视频时自动复位），撤回也回到**原来那一秒**（以前为了绕开这个自激，会退回 1 秒前）
- 修复撤回后**没有任何反馈**：新弹出的「已撤回」提示会被旧 toast 的清理逻辑一起抹掉
- 新增设置「**跳过偏移（秒）**」：在数据库给的时间戳上再挪一点。正数＝多跳（跳过 OP 后的黑屏／静帧），负数＝少跳（保留 OP 尾巴）；最多减到片段起点，不会倒着跳
- 「撤回提示秒数」默认值 8 秒 → **4 秒**（停留太久挡住画面），老配置会自动迁移

### 0.4.3
- 修复**多季合集里「第几段配哪一季」配错**的问题。典型稿件：一个视频装了「第三季 1–16 + 第四季 1–19」，在候选里选第 3 季却说「合集第 2 话 → 第一季第 2 话」，选第 4 季又说「→ 第二季第 2 话」——**取的是错误季的时间戳**
  - 现在**分P标题自己写的季号就是锚点**：「第三季1」这一段从数据库的第 3 季条目开始配。以前只按累计话数从家族最早一季往后数，碰到「只投了后几季」的稿件必然错位
  - 顺带修了两个让上一条失效的隐性 bug：数据库条目的季号读不出来（「3rd season」这种序号写在 season 前面的写法不认；季链里的条目名是字符串却被当成对象读）
  - 季链沿续集关系展开时不再按跳数砍断（长番要 4 跳才够得到第 1 季，原来卡在 3 跳会少一季）
  - 分P标题**没写季号**时仍然退回原来的累计话数贪心，不影响老稿件
- 没对上数据库条目的分段现在**一律不跳**（以前只要凑出了条目就照跳，会跳到错误的季上）
- 末尾的花絮／预告（没有季号、没有话号、时长明显偏短，如「1分钟」）不再算进分段，避免整段话数对不上导致整季失效
- 校验跳转区间时会带上视频实际时长：超过视频长度的区间直接丢弃，99 秒的彩蛋片段不会被误跳
- 老绑定里由旧算法算出的季链会自动忽略（`chainVer` 已升到 4），重开面板保存一次即可

### 0.4.2
- 修复「**单独发一季**」的稿件被误判成多季连播：「第三季】全12话」是「第 3 季，共 12 话」的意思，之前被当成「N季…N话」的多季信号，于是单季投稿也会弹出没用的「季边界」面板
- 修复季链**漏掉最早的几季**导致集号整体错位：从第 3 期出发时，沿续集关系只能收到「第 2 期 + 第 3 期」（祖父辈永远补不进来），于是「合集第 1 话」被算成第 2 期第 1 话。**这会让脚本取错季的时间戳，不只是显示问题**
- 修复「第三季」被认成**第一季**：番名基础名和第一季完全相同时，相似度满分会把第一季排到第一，现在会按标题里的季号纠偏
